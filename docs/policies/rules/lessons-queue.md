# Lessons: the index returns as a queue, and every entry names its gate (2026-09-02, owner)

One of [this repo's local rules](../local-rules.md), where "above" and "below" mean earlier and later in its list.

`docs/learning/lessons.md`, `lessons-evidence.md`, `scripts/check-lessons.mjs` and the `lessons:check` script were deleted earlier the same day (`f8f807ad`). The owner's LATER ruling that day supersedes that deletion: a lesson may exist as prose first, but it has to become a gate, and the sooner the better. So this repo keeps a lessons queue again — in the canon's current shape only: every entry names the gate that will retire it, the entry is deleted in the commit that lands that gate, and a gate counts only once it has been made to go red by reintroducing the defect.

**Why:** three revisions of the fleet lessons rule landed on 2026-09-02. The first mandated a permanent index; the second abolished it, and this repo applied the abolition the same day (84 entries and 928 lines of evidence deleted); the third — the current canon — restores the waiting room the second removed, because 13 of 20 census repos had never migrated and abolishing the index would have deleted their queues rather than graduating them. What made the 84 entries worthless was never that they were prose. It was that not one named a gate, so nothing ever left the file.

**How to apply:** start EMPTY — do not restore the deleted files from history. That audit found the large majority of the 84 were instances of a rule the constitution or these local rules already state, narrow notes about code since rewritten (three concerned Phaser, which this repo no longer depends on), or lessons whose gates already existed and whose headers already carried the war story. Write a new entry only when this repo pays for something AND you can name the check that will retire it; if you cannot name one, it is not a lesson — fleet-wide knowledge stages in `canon-candidates.md` for the constitution, repo-only knowledge comes here, and the rest is dropped. The one promotion from that audit stands: `npm run verify` is named in Gates as THE gate, because its `&&` chain makes the exit code the answer, which retired three separate lessons about piped output masking a gate's exit code.
