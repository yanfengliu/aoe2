**IR3 — P2: Greedy reservation can leave an unstarted foundation waiting although all occupants have a legal exit.** `src/game/simulation/bridge/foundationStart.ts:228–231` supplies all units before all animals to `moveOff`. In `src/game/simulation/bridge/footprintClearing.ts:143–158`, each occupant irrevocably reserves its first legal perimeter cell. Units can share free subcell capacity at lines 151–153; an animal requires an exclusive, currently uncrowded cell at lines 155–156. Failure of any later search returns false, and the start waits without moving anybody. The same unchanged ordering and occupancy repeat on the next attempt.

A minimal asymmetric-capacity fixture is an own unit and a sheep inside the site's footprint, two reachable land exits, all other exits blocked. Make the unit's first BFS exit empty and the other exit occupied by one existing unit with free subslots. The first unit claims the empty exit, after which the sheep rejects both the reserved exit and the crowded exit. The legal assignment is to put the moving unit in the shared exit and the sheep in the empty exit. The existing fixture uses a House at `(4,4)`, occupants at `(5,5)` and `(4,4)`, and controlled exits (`tests/simulation/foundationStartAnimals.test.ts:70–85,113–125`). It already checks two empty exits, one shared exit with 14 or 15 existing units, and an animal's refusal of an occupied exit (`:347–386`), but does not exercise this asymmetric pair of exits. The minimal reproduction needs the extra pre-existing unit on the alternative exit rather than the unit's first choice. This review did not execute it.

Animal-first ordering closes that concrete unit/sheep counterexample but does not establish the general unit assignment contract. `src/game/simulation/bridge/cellPassability.ts:249–286` admits units according to domain and, for gates, their owner/team. The unchanged, outside-diff rule at `src/game/simulation/gates.ts:51–62` admits only the gate owner or its ally. `foundationStart.ts:224–227` also permits an enemy unit to be cleared when it is actively building its own adjacent site. Thus two eligible units can have different exit sets: an owner unit can consume the last ordinary subslot while a foreign builder cannot use the owner's gate, even though the owner unit could have used that gate. This is a concrete reason to cover restricted unit alternatives, not a request for a general path-planner rewrite. A bounded reservation reassignment with the existing search order, capacities and all-or-none world mutation is a reasonable repair. Preserve negative cases where no assignment exists. Root accepted IR3 for reproduction and assigned a separate worker; its repair and execution results are not accepted by this frozen-target report.
