# The computer trains each soldier line for a reason, as Definitive Edition's AI does

Status: active
Owner: ai-train-reasons worker (worktree `ai-train-reasons-1106`) for the Claude coordinator
Created: 2026-11-06
Updated: 2026-11-11

## Problem and outcome

At every decision this AI asks the first idle producer of each `pickUnitMix` entry for that unit whenever the purse allows (`bridge/systems/aiSystemProductionPhase.ts`, the mix loop; `ai.ts` `pickUnitMix`). Definitive Edition's AI resets every train goal on each pass and trains a soldier line only while some rule gives it a reason (units.per 8-71). Work 147 M1 measured the cost of the difference: on 83 of 93 Castle Age waits of a minute or more for a Siege Workshop or Monastery, the army spent the waiting building's price. The owner adopted DE's rule on 2026-11-06 ("Yes, own lane"; spec §13.2, "Each line for a reason").

The outcome: the computer trains each soldier line for a reason, as DE's AI does, and its army still attacks and defends.
