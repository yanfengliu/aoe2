# Worktree target ownership boundary

Capture canonical validated deletion roots and link targets before unlinking. Exempt only a target proven physically inside the owned deletion tree; preserve canonical external targets and treat unresolved identity as protected. Every unlink, fresh scan, admin-directory, merge and dirty guard remains mandatory.
