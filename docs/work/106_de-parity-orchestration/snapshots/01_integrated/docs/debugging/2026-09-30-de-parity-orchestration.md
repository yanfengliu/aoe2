## Root cause

The bounded defects were separate representation gaps: conflated contact/damage roles, stale source transcription, incomplete cue hydration, and missing persisted gathering occupation behind the resource HUD.

## Fix

Separate `unitAttackType` from contact role; re-source only projectile accuracy/delay fields while retaining source IDs and exact decimal seconds; preserve validated detached known cue participant fields while retaining legacy absence; implement nullable unit resource occupation through assignment/clear metadata writes with explicit old user-save and replay-format boundaries. Preserve the existing mutable gatherer task path and same-tick traffic intent. Through-impact recording coverage and bounded occupation evidence now live in the canonical plan/handoffs.
