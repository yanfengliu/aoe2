## Findings and dispositions

- **P1 MED (also S3, T8) — an older save keeps the old radius on the seven types that already saw** (a starting Town Center 7, a Fortress Castle 9). Kept, and the claims narrowed. A saved radius already includes the Town Watch, Town Patrol or civilization bonus of whoever owned the building, and a converted building carries its old owner's, so no base can be split back out of it. Spec §12.2 and the changelog now say so. `buildingVision.test.ts` "a building that already sees keeps the radius it was saved with" pins it.
- **P2 LOW — the repair runs on every load and replay world, with no version gate.** Kept. The same test asserts that a save from this build loads unchanged, so the repair touches nothing in a save made after the change.
- **P3 LOW — only the schema-2 live load of the repair is tested.** Not fixed; bound stated. Schema-1 blobs in tests are built from current-code state, so they cannot hold a sightless building. The replay world goes through the same `bootScenarioOrLoad`.
- **P4 LOW, latent — the explicit-radius seed branch ignores Town Watch and Town Patrol.** Not changed. An explicit radius is a fixture's exact choice, and no fixture or map seeds either technology.
- **P5 LOW — a save from this build opened in an older build would leak three quarters of an even building's sight.** Overtaken by the layers and the building slot. An older build never asks for a `:buildings` player and never reads `aoe2.buildingVisibility`, so nothing leaks there. Its buildings just see as that build's did.

- **S1 MED — the worst tick is unmeasured, and every recompute re-stamps every building.** Confirmed and fixed. A stress probe (148 buildings with Town Watch and Town Patrol, 30 Militia a side) measured one recompute at up to 9.2 ms against 0.54 ms, and fight ticks at up to 6.4 ms of recompute against 0.2. `LayeredVisibilityMap` puts each owner's buildings in an engine map of their own, which a unit's move never recomputes: the fight's recompute is back at the control's, at most 0.14 ms a tick against 0.13. A later same-world A/B found that the state the layer added still cost about +0.27 ms/tick, because the engine fingerprints every state slot twice a tick. The building slot, which holds only what a load cannot rebuild, answers that (review 2).
