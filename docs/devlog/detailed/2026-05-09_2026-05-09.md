## 2026-05-09T13:00:00-07:00 - Phase-6.C.2 post-hoc observation oracle

### Action

After a playtest run completes, an optional advisory LLM call examines the final-tick screenshot + a textual run summary and emits a `{verdict: 'looked-fun' | 'looked-broken' | 'inconclusive', notes: string}` envelope field. Disabled by default; opt in via `--observation` CLI flag or per-corpus-row `observation: true`. Advisory only — does NOT affect CI exit codes; engineHalt remains the regression signal.

- New `src/game/playtest/observationOracle.ts` — pure `runObservationOracle(input) → ObservationVerdict` over an `LlmProvider`. Builds a single `set_observation` tool schema, sends `[image?, text]` content blocks, parses with defensive fallbacks (null toolInput, wrong toolName, unknown verdict string → all → 'inconclusive'). `buildTraceSummary(...)` helper formats envelope fields into the textual prompt component.
- `RunnerEnvelope.observation?: ObservationVerdict` field. Runner now stashes the last in-loop screenshot AND captures a true post-loop screenshot (only when `stopReason !== 'engineHalt'` — on a clean exit a post-loop screenshot failure escalates to engineHalt rather than silently shipping the stale in-loop screenshot to the oracle).
- `RunLlmPlaytestResult.finalScreenshotPng` exposes the chosen screenshot for downstream callers.
- `scripts/playtest-llm.mjs` — `--observation` flag; runs the oracle after the loop (skipped when `errorMessage === 'cost-budget-exceeded'` to honor the operator's budget cap). Wraps in try/catch so oracle failure doesn't mask the run's primary stopReason. Counts dispatch rejections from the trace. Rolls `verdict.costUsd` into `envelope.totalCostUsd` so corpus rollups don't underreport spend.
- `corpusLlmSchema.ts` — `observation?: boolean` on `PlaytestLlmCorpusRun` with parse validation.
- `scripts/playtest-corpus-llm.mjs` — forwards `--observation` to sub-invocation when truthy.
- `design/spec-final.md` — new §15.7 "LLM-Agent Playtest Harness (Internal Tooling)" documenting the operator-visible mechanics so future autonomous handoffs have a single source of truth.
